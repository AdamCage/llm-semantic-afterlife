# PDF releases of the manuscript

Committed outputs of `bash paper/compile.sh`.
English is canonical; Russian is a translation of `paper/main.tex`
after the ADR-0019 rewrite (blockwise kernel, `B=1024`,
Clopper–Pearson intervals). Recompile both after editing either TeX
file.
The English PDF built from the assembled `main.tex` supersedes earlier English builds, which predate that narrative; `main.ru.tex` has not been realigned, so `semantic-afterlife-ru.pdf` is not a translation of the assembled paper until it is.
