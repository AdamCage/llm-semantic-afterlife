# Visual direction

Aim for an explanatory film, not a stack of paper screenshots. Decide what the
viewer should notice first in each beat. Use generous safe areas and large text.
At 1080p, main titles around 80–110 px and important explanation around 36–48 px
worked in the reference production; this is a baseline, not a universal rule.
Inspect both full-size and reduced-size frames. Plot tick labels can require a
separate panel or crop/re-layout to remain readable. Never crop away uncertainty,
units, denominators, censoring marks or the relevant comparison.

Use real plots to show results, vector/code animation to explain mechanisms,
and AI imagery for visual metaphors or chapter changes. A loop-shaped artwork
is not a phase portrait. A projected embedding cloud is not a statistical test.
Label these distinctions visibly and say them when misunderstanding is likely.

For AI artwork, use the available built-in image-generation tool and its skill.
Generate a coherent small visual family: restrained palette, matching materials,
lighting, aspect ratio and negative space for typeset text. Generate typography
and measured axes in code. Preserve final prompts, origin/model when known,
local files, hashes and billing context. If the built-in tool is unavailable,
explain the available fallback instead of silently substituting another paid API.
Do not invent a model name or price the tool did not expose.

For figures, read the exact tidy table and metadata first. Prefer a faithful
re-layout over a screenshot with microscopic labels. Keep comparisons within
their actual estimands. A point with an interval containing zero is not an
established sign; an undefined estimate is not a zero. Do not pool unlike
families, representations or protocols to simplify the image.

The generic renderer provides entrances, cards, process arrows, figures,
quotations and slow movement on artwork. Extend it for the actual mechanism:
moving windows, accumulation, branching, uncertainty propagation, sampling,
timelines or whatever this study needs. Use Remotion frame-based animation,
never wall-clock timers or CSS keyframes. Keep motion purposeful and restrained.

When switching data panels, align the switch with the spoken subject. It is
misleading to show one condition while the narrator discusses another. Local
ASR timestamps help place these transitions. Do not animate a point through
intermediate values as if those were observed measurements; indicate reveals
or illustrative motion explicitly.

For print-equivalent scientific exports preserve the host repository's figure
bundle requirements. Video display copies are derivative editorial assets;
they do not replace source figures, tidy data or captions.
